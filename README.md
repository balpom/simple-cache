# balpom/simple-cache
## Simple PSR16 cache simple realisation.

Simple realisation of Psr\SimpleCache\CacheInterface.
Cache storage based on [balpom/storage](https://github.com/balpom/storage) library.

### Requirements 
- **PHP >= 8.2**

### Installation
#### Using composer (recommended)
```bash
composer require balpom/simple-cache
```
